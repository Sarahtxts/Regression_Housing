# 🏠 Regression Analysis on Housing Prices

## 📖 Overview

This project presents a hands-on approach to predicting housing prices using **Linear Regression** and **Exploratory Data Analysis (EDA)** in Python.  
You will learn to preprocess real-world housing datasets, build regression models, and visualize data relationships to interpret which features most affect property values.

***

## 🎯 Objectives

- Analyze and preprocess housing data using Python.
- Perform **EDA**, data cleaning, feature selection, and transformation.
- Build and evaluate a **Linear Regression** model for price prediction.
- Visualize numerical and categorical feature relationships.
- Interpret model performance using statistical metrics (R², MAE, RMSE).

***

## 📊 Methodology

1. **Data Import & Cleaning**
   - Handle missing values and outliers.
   - Convert categorical variables into numerical format.

2. **Exploratory Data Analysis (EDA)**
   - Visualize feature distributions, correlations, and outlier impacts.
   - Use heatmaps and pair plots for in-depth exploration.

3. **Feature Engineering**
   - Extract year/month from date features if available.
   - Normalize/standardize features for better model performance.

4. **Model Building**
   - Implement **Linear Regression** using `scikit-learn`.
   - Perform train-test split and fit the model.

5. **Evaluation & Visualization**
   - Calculate R², **Mean Absolute Error (MAE)**, **Root Mean Square Error (RMSE)**.
   - Compare predicted vs. actual prices with visual plots.

***

## 💡 Key Insights

- **Area and location** are major influencers in housing price prediction.
- Data normalization and outlier removal boost prediction accuracy.
- Visual EDA helps uncover important data relationships.
